Installare DVWA su Docker in Windows

Prerequisiti

  • Windows 10 22H2 o Windows 11 23H2, o versioni successive, anche Home;
  • 8 GB di RAM;
  • Virtualizzazione attiva nel BIOS.

1. Installa WSL

Docker Desktop lo usa per far girare i container. Apri PowerShell come amministratore e lancia:

wsl --install --no-distribution

Al termine riavvia il PC. Se WSL ce l'hai già, il comando si limita ad aggiornarlo.

2. Installa Docker Desktop

Apri PowerShell (come utente normale):

winget install -e --id Docker.DockerDesktop

Se ti chiede di accettare i termini, scrivi Y e premi Invio.

Avvia Docker Desktop dal menu Start, accetta le condizioni e aspetta che in basso a sinistra compaia Engine running (se non dovesse funzionare, prova innanzitutto a riavviare la macchina).

Chiudi e riapri PowerShell, poi controlla che Docker risponda:

docker version
docker compose version

3. Scarica DVWA

Crea una cartella per il laboratorio ed entraci (fallo pure da Esplora File).

Dentro la cartella, fai tasto destro su uno spazio vuoto e scegli Apri nel Terminale. Su Windows 10 tieni premuto Maiusc mentre fai tasto destro e scegli Apri finestra di PowerShell qui. I comandi che seguono vanno lanciati da questa finestra.

Scarica il file di configurazione ufficiale di DVWA:

curl.exe -L -o compose.yml https://raw.githubusercontent.com/digininja/DVWA/master/compose.yml

Scarica le immagini del sito e del database:

docker compose pull

4. Avvia il container

docker compose up -d

Al primo avvio il database impiega qualche secondo a prepararsi.

5. Primo accesso

  1. Apri http://localhost:4280
  2. Accedi con utente admin e password password
  3. Clicca Create / Reset Database
  4. Accedi di nuovo con le stesse credenziali
  5. In DVWA Security scegli Low e conferma con Submit

Fermarlo e riavviarlo

DVWA riparte da solo ogni volta che apri Docker Desktop. I comandi vanno lanciati dalla cartella del laboratorio.

Per fermarlo:

docker compose stop

Per riavviarlo:

docker compose start

Per eliminare i container e il database:

docker compose down -v

Troubleshooting

  • "docker" non è riconosciuto: chiudi e riapri PowerShell dopo l'installazione
  • Docker Desktop segnala la virtualizzazione disattivata: attivala nel BIOS, la voce si chiama Intel VT-x o AMD-V a seconda del processore
  • La porta 4280 è già occupata: apri compose.yml e cambia 4280 con un altro numero, ad esempio 4281, poi usa quello nell'indirizzo
