Whisper in Docker: trascrivere audio in testo sul server di casa

Il comando giusto dipende da due cose: se hai una scheda video NVIDIA e quale sistema operativo usi. Il modello dipende dalla potenza del computer.

1. Che scheda video hai?

Windows: Gestione attività, Prestazioni, GPU. Il nome della scheda è in alto a destra.

Linux:

lspci | grep -i -E "vga|3d"

Se compare NVIDIA vai al punto 3, altrimenti al punto 2.

2. Senza scheda NVIDIA

Schede AMD o Intel, nessuna scheda video, Raspberry Pi, Mac. Il comando è lo stesso su Windows, Linux e macOS:

docker run -d --name whisper --restart unless-stopped -p 9000:9000 -e ASR_MODEL=medium -e ASR_ENGINE=faster_whisper -v whisper-cache:/root/.cache onerahmet/openai-whisper-asr-webservice:latest

ASR_MODEL è il punto in cui scegli il modello. Il valore giusto per il tuo computer è nella tabella al punto 4.

3. Con scheda NVIDIA

Su tutti i sistemi, prima controlla il driver:

nvidia-smi

In alto a destra compare CUDA Version: deve essere 12.9 o superiore. Se è più bassa, o il comando non viene trovato, aggiorna il driver NVIDIA.

Windows

Driver 576 o successivo. Docker Desktop passa già la scheda al container, non serve altro:

docker run -d --name whisper --restart unless-stopped --gpus all -p 9000:9000 -e ASR_MODEL=large-v3 -e ASR_ENGINE=faster_whisper -v whisper-cache:/root/.cache onerahmet/openai-whisper-asr-webservice:latest-gpu

Linux

Driver 575 o successivo. In più serve NVIDIA Container Toolkit, che permette a Docker di usare la scheda. Comandi ufficiali NVIDIA per Ubuntu e Debian:

curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
sudo apt-get update && sudo apt-get install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker

Poi lo stesso comando di Windows:

docker run -d --name whisper --restart unless-stopped --gpus all -p 9000:9000 -e ASR_MODEL=large-v3 -e ASR_ENGINE=faster_whisper -v whisper-cache:/root/.cache onerahmet/openai-whisper-asr-webservice:latest-gpu

Rispetto al punto 2 cambiano due cose: --gpus all e il tag latest-gpu alla fine. ASR_MODEL si sceglie in base alla memoria della scheda, che leggi nell'output di nvidia-smi (per esempio 8188MiB vuol dire 8 GB).

4. Quale modello scegliere

Più è grande il modello, più è preciso sui nomi propri e sui termini tecnici, ma anche più lento.

Il tuo computerValore di ASR_MODEL
Senza NVIDIA, PC vecchio o Raspberry Pismall
Senza NVIDIA, PC recentemedium
NVIDIA con 4 GB di memoriamedium
NVIDIA con 6 GB o piùlarge-v3

I valori sono indicativi: se la trascrizione è troppo lenta o si blocca, scendi di un gradino.
