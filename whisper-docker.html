Whisper in Docker con Scriberr: trascrivere audio in testo sul server di casa

Scriberr è un'interfaccia web, gratuita e open source, che fa girare Whisper sul tuo computer: carichi un file dal browser, anche dal telefono, e ottieni testo e sottotitoli. Riconosce chi sta parlando e può fare riassunti con un'IA in casa.

Il file da creare dipende da due cose: se hai una scheda video NVIDIA e quale sistema operativo usi.

Prerequisiti

  • Docker installato. Su Windows e Mac, Docker Desktop. Se non ce l'hai, su Windows segui i primi passi della guida Pi-hole;
  • Processore a 64 bit: PC Intel o AMD, Mac con chip Apple, Raspberry Pi 4 o 5 con sistema a 64 bit;
  • Almeno 8 GB di RAM e 20 GB liberi su disco: al primo avvio scarica i modelli.

1. Che scheda video hai?

Windows: Gestione attività, Prestazioni, GPU. Il nome della scheda è in alto a destra.

Linux:

lspci | grep -i -E "vga|3d"

Se compare NVIDIA vai al punto 3, altrimenti al punto 2.

2. Senza scheda NVIDIA

Schede AMD o Intel, nessuna scheda video, Raspberry Pi, Mac.

3. Con scheda NVIDIA

Su tutti i sistemi, prima controlla il driver:

nvidia-smi

In alto a destra compare CUDA Version: deve essere 12.6 o superiore. Se è più bassa, o il comando non viene trovato, aggiorna il driver NVIDIA (versione 560 o successiva).

Schede RTX serie 50 (5060, 5070, 5080, 5090): serve un'immagine dedicata, che a novembre 2026 non risulta ancora scaricabile già pronta. Usa la versione del punto 2, che funziona su processore, oppure controlla la pagina del progetto.

Solo su Linux: NVIDIA Container Toolkit

Permette a Docker di usare la scheda. Su Windows non serve, Docker Desktop passa già la scheda al container. Comandi ufficiali NVIDIA per Ubuntu e Debian:

curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
sudo apt-get update && sudo apt-get install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker

4. Avvio

Dalla cartella scriberr, scarica l'immagine e avvialo:

docker compose pull
docker compose up -d

Il primo avvio richiede diversi minuti: scarica i modelli e prepara l'ambiente. Segui l'avanzamento con:

docker logs -f scriberr

È pronto quando compare Scriberr is ready. Esci dai log con Ctrl+C, il container resta acceso. Gli avvii successivi sono immediati.

Primo accesso

  1. Apri http://localhost:8080 dallo stesso computer, oppure http://IP_DEL_SERVER:8080 da un altro dispositivo di casa
  2. Alla prima apertura compare Setup Admin Account: scegli nome utente e password
  3. Carica un file audio o video, scegli il modello e la lingua, avvia la trascrizione
  4. A trascrizione finita esporti in TXT, SRT (sottotitoli con i tempi) o JSON

L'IP del server lo trovi con ipconfig su Windows o hostname -I su Linux. Assegnagli un IP fisso nel router, così l'indirizzo non cambia.

Dal telefono, aprendo la pagina in Chrome o Safari puoi aggiungerla alla schermata Home: si comporta come un'app.

5. Quale modello scegliere

Il modello si sceglie dall'interfaccia, a ogni trascrizione. Più è grande, più è preciso sui nomi propri e sui termini tecnici, ma anche più lento. Per l'italiano usa Whisper.

Il tuo computerModello
Senza NVIDIA, PC vecchio o Raspberry Pismall
Senza NVIDIA, PC recentemedium
NVIDIA con 4 GB di memoriamedium
NVIDIA con 6 GB o piùlarge-v3

La memoria della scheda la leggi nell'output di nvidia-smi (per esempio 8188MiB vuol dire 8 GB). I valori sono indicativi: se la trascrizione è troppo lenta o si blocca, scendi di un gradino.

6. Riconoscere chi parla (facoltativo)

Per separare le voci in una riunione o in un'intervista, Scriberr usa un modello che si scarica da Hugging Face. L'elaborazione resta sul tuo computer: serve solo il permesso per scaricarlo.

  1. Crea un account gratuito su huggingface.co
  2. Apri pyannote/speaker-diarization-community-1 e accetta le condizioni
  3. In Access Tokens crea un token di tipo Read e copialo
  4. In Scriberr apri Settings e incollalo nel campo Hugging Face Token

Con l'immagine NVIDIA puoi anche scegliere Sortformer, che non richiede il token.

Fermarlo, aggiornarlo, eliminarlo

I comandi vanno lanciati dalla cartella scriberr. Per fermarlo:

docker compose stop

Per riavviarlo:

docker compose start

Per aggiornarlo, cambia il numero di versione nella riga image di docker-compose.yml, poi:

docker compose pull && docker compose up -d

Per eliminare il container, le trascrizioni e i modelli scaricati:

docker compose down -v

Troubleshooting

  • "Unable to load audio stream": manca SECURE_COOKIES=false nel file. Aggiungila e rilancia docker compose up -d
  • La pagina non si apre per diversi minuti: è il primo avvio che scarica i modelli. Controlla con docker logs -f scriberr
  • Errore "out of memory (14)" nei log, su Linux: è un problema di permessi sulla cartella dei dati. Lancia id -u e id -g e metti i due numeri in PUID e PGID
  • Gli altri dispositivi non raggiungono la pagina, su Windows: apri la porta nel firewall, da PowerShell come amministratore: 
    New-NetFirewallRule -DisplayName "Scriberr" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
  • La porta 8080 è già occupata: cambia "8080:8080" in "8081:8080" e apri la pagina sulla porta 8081
  • Con NVIDIA, errore "could not select device driver": su Linux manca NVIDIA Container Toolkit, su Windows aggiorna Docker Desktop e il driver
